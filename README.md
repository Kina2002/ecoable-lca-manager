# 에코에이블 LCA 프로젝트 관리 (가칭)

에코에이블컨설팅㈜ 전과정정책본부의 **제품 전과정평가(LCA) 컨설팅** 업무를 돕는 프로젝트 관리 앱입니다. LCA에서 가장 오래 걸리고 자주 막히는 **고객사 데이터 수집**을 중심으로, 프로젝트를 계약부터 사후관리까지 한 화면에서 관리합니다.

> ⚠️ 이 저장소는 박기나가 에코에이블컨설팅 지원을 위해 만든 **포트폴리오용 시연 프로젝트**입니다. 에코에이블컨설팅의 공식 서비스가 아니며, 모든 회사·인물·프로젝트 데이터는 가상입니다.

## 진행 과정 요약

1. **Salesforce 시연 앱** — 커스텀 오브젝트, Flow 5개, Prompt Builder AI 메일 초안, LWC 버튼·홈 화면, Apex 테스트 22개(커버리지 96~99%)로 데이터 수집 관리 앱을 만들었습니다. 자세한 내용: [salesforce-demo/README.md](salesforce-demo/README.md)
2. **자료조사** — 회사 포트폴리오, ISO 14040/44·14067, 환경성적표지 제도, EU 배터리법·CBAM, PACT·Catena-X, 시중 LCA 플랫폼을 조사했습니다.
3. **재설계** — 회사에 링크로 제출할 수 있도록 Salesforce 없이 동작하는 웹앱으로 다시 설계했습니다.
4. **공개 데이터 조사** — 샘플 데이터를 실제 제도에 맞추기 위해 공공데이터포털·환경성적표지 작성지침·PACT·Catena-X 등을 조사하고, "실제 제품 종류 + 가상 회사" 원칙으로 설계에 반영했습니다.

## Salesforce 시연에서 배운 점 (웹앱 설계에 반영)

| 배운 점 | 반영 |
| --- | --- |
| AI는 같은 자료를 받아도 매번 다르게 쓰고, 목록을 빠뜨리거나 다른 묶음에 넣을 수 있다 | 메일의 자료 목록은 규칙으로 만든다 |
| 보낼 내용이 없는데 메일을 지어낼 수 있다 | 해당 자료가 없으면 초안 대신 한 줄 안내 |
| 틀리면 안 되는 판단(빈 정보, 기한, 수신자)은 계산으로 정해야 한다 | 확인 필요 정보·메일 분류·추천을 모두 규칙으로 계산 |
| "받았다"와 "써도 된다"는 다르다 | 자료 상태를 제출됨·검토 중·승인으로 나눔 |
| 프로젝트가 많아지면 표가 길어진다 | 주의 필요만·검색·단계 거르기·더 보기 |

## 웹앱 실행 (개발 중)

```bash
cd web
python -m http.server 5173
```

브라우저에서 `http://localhost:5173` 을 엽니다. 배포 후에는 공개 링크로 열 수 있습니다.

현재 구현된 것은 **설계서 v02 9-3장의 7개 가상 프로젝트 목록 조회와 10단계 선택 필터**입니다.
회사·제품·목적·현재 단계·목표일을 보여주며 휴대폰에서는 카드로 표시합니다.
위쪽의 10단계 버튼으로 단계별 건수를 보고 해당 프로젝트만 골라 볼 수 있습니다. 같은 단계를 다시 누르거나 '전체 보기'로 해제합니다.
프로젝트 등록·수정·상세·저장과 나머지 기능은 하나씩 함께 구현합니다.
`web/js/constants.js`·`rules.js`의 나머지 v02 규칙은 해당 기능을 만들 때 반영합니다.

## 기술

- 웹앱: HTML · CSS · JavaScript (프레임워크·빌드 도구 없음), 브라우저 저장(localStorage), 규칙 기반 메일 템플릿
- 시연 앱: Salesforce (Custom Object, Flow, Apex, LWC, Prompt Builder)
- 디자인 참고: 에코에이블컨설팅 홈페이지의 글꼴(Pretendard)과 색 분위기 (로고는 사용하지 않음)
