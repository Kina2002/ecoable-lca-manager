## 보관 원칙

- 실제 JPEG/PNG 형식에 맞춰 원본을 보관했다. 이미지 내용을 편집하거나 과거 화면을 재연하지 않았다.
- 현재 캡처는 저장값을 바꾸지 않고 화면 이동·예시/이력 펼침으로 기록했다.
- 긴 전체 페이지 캡처는 시간 제한으로 생성하지 못해 분할 화면을 사용했다.
- 사용자가 명시한 이번 가상 실습 묶음은 비공개 GitHub handoff 폴더에 함께 보관한다. 공개 데모에는 포함하지 않는다.
