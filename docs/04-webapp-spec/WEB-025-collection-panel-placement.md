# WEB-025 자료 요청 안으로 완료 확인 이동

## 사용자 요청

2026-10-18 사용자는 상세 공통 상단에 있던 ‘자료 수집 완료 확인’을 자료 요청 탭 안으로 옮겨 달라고 했다. 자료 확인→수집 완료 판단→검토 시작이 한 탭에서 이어지도록 배치를 바꾼다.

## 변경

- 수집·검토 완료 확인 컴포넌트를 **자료 요청 탭 상단**, 요청 등록 폼과 상태별 목록 앞에 배치한다. 개요·범위와 다른 탭에서는 표시하지 않는다.
- 수집 단계(3)의 제출 확인·검토 시작, 검토 단계(4)의 승인 건수·계산 이동, 계산 단계(5)의 검토 완료 안내를 같은 위치에 표시한다.
- 같은 탭으로 이동시키던 **자료 요청에서 확인** 버튼과 콜백은 제거한다.
- 요청 폼·목록은 별도 내용 컨테이너에 렌더해 완료 확인 영역을 덮어쓰지 않도록 한다. 단계 이동은 완료 확인 영역만 다시 만들며 요청의 작성 초안·상태 필터를 유지하는 기존 구조를 따른다.

## 보존하는 동작

수집 완료는 현재 요청 최소 한 건과 모든 제출 확인, 검토 완료는 모든 승인이 필요하다. 누락 자료 안내, 최신 기록 재검사, 미저장 수집 마감일 보호, 3→4·4→5만 이동, 다른 탭의 계산·해석·보고서 기능은 그대로다. 저장 키나 기존 입력 데이터는 변경하지 않는다.

## 확인 범위

변경 JavaScript 4개 파일의 구문과 Git 공백을 확인했다. 이번에는 테스트를 추가·실행하지 않았다. 실제 미리보기에서 자료 요청 탭 상단의 완료 확인과 요청 폼 배치·이동 버튼 제거를 확인했다. 단계 이동·입력 초안·필터 유지의 새 실행 검증은 하지 않았으며 이전 SPEC의 통과 수를 이번 결과로 주장하지 않는다.
