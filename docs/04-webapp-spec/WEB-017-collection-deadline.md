# WEB-017 별도 자료 수집 마감일과 미정 표시

## 1. 사용자 합의

2026-10-17 사용자는 자료 현황의 D-day를 개별 요청이 아닌 **자료 수집 마감일** 기준으로 정했다. 계약·범위 단계에서는 아직 자료 수집 일정을 협의하지 않았을 수 있으므로 **미정**을 허용한다.

## 2. 동작

- 프로젝트 목표일, 자료 수집 마감일, 개별 요청 제출 기한은 각각 별도 날짜다.
- 목록의 자료 현황 D-day는 `collectionDueDate`로 계산한다. 요청이 0건이거나 모두 승인됐어도 수집 단계에서는 이 날짜를 계속 센다.
- 날짜가 없으면 계약·범위·수집 단계 모두 미정이다. 요청이 없다는 이유로 수집을 완료 처리하지 않는다.
- 현재 업무 프로세스에서 수집을 지난 데이터 검토(4)~완료(10) 단계는 자료 수집 완료로 표시한다. 검토 완료나 프로젝트 전체 완료를 뜻하지 않는다. 단계 변경 기능을 추가한 것은 아니다.
- 승인 건수와 가장 이른 미승인 요청의 번호·상태·기한은 보조 정보로 보여준다. 개별 요청의 D-day 계산은 유지한다.
- 상세의 개요·범위 탭 위쪽에 자료 수집 일정을 추가했다. 계약·범위·수집 단계에서 날짜를 저장·수정하고, 비워서 미정으로 되돌릴 수 있다. 검토 이후는 읽기 전용이다.
- 숫자 8자리 입력·달력, 실제 달력 날짜 검사, 저장 실패 안내와 다른 탭의 변경 감지를 지원한다. 새 프로젝트 등록 시에는 자동 날짜를 만들지 않는다.
- 라온소재 샘플은 앱을 연 날에서 7일 뒤를 가상 수집 마감일로 제공한다. 계약·범위 샘플은 빈 날짜다. 직접 저장한 날짜와 명시적으로 비운 값은 새로고침 후에도 유지된다.
- 날짜가 지나면 D+로 계속 표시한다. 자정 이후에는 기존 날짜 배지 갱신을 사용한다.

## 3. 저장과 호환

기존 `ecoable-lca-manager.projects.v1`에 선택 필드 `collectionDueDates`를 추가한다. 프로젝트 ID를 키로 하고 날짜 또는 빈 문자열을 저장한다. 이 필드가 없는 기존 기록은 쓰기 없이 읽는다. 명시적 빈 문자열은 샘플 날짜를 덮어 미정을 유지한다.

프로젝트 등록 시 이 필드를 보존한다. 범위·연구원·요청 저장 키는 수정하지 않는다. 날짜 저장에 실패하면 화면의 저장된 날짜도 바꾸지 않는다. 손상된 저장본은 덮어쓰지 않고 수집 일정 확인 필요로 안내한다.

## 4. 확인

- 자동 검사 138개 통과(기존 131개 + 수집 일정 7개).
- 요청 0건과 별도 수집 D-day, 목표일과 구분, 미지정·잘못된 날짜, D+와 단계별 종료, 기존 저장본 호환, 명시적 미정, 재등록 후 보존, 다른 저장 키 보존, 동시 변경·쓰기 실패를 확인했다.
- 실제 미리보기에서 라온소재의 8자리 입력→날짜 저장→목록 D-day→새로고침 복원, 빈 값 저장→미정, 원래 샘플 날짜 복원을 확인했다.
- 실제 목록에서 계약·범위 미정, 수집 D-day, 이후 단계 자료 수집 완료와 좁은 화면의 카드 배치를 확인했다.
- 실제 자정 대기·다른 브라우저 동시 조작은 수행하지 않았다. 해당 계산·동시 변경 거절은 자동 검사로 확인했다.

## 5. 면접 설명

“프로젝트 전체 목표일과 자료 수집 마감일을 나눴습니다. 아직 일정을 합의하지 않았다면 미정으로 두고, 요청 기록이 없어도 합의한 수집 날짜가 있으면 남은 시간을 보여줍니다. 자료 수집, 자료 검토, 프로젝트 전체 완료도 각각 구분합니다.”
