# WEB-036 앱 이름·메뉴 순서·홈 할 일 바로가기

작성일: 2026-10-18

## 사용자 요청과 변경

- 왼쪽 위 앱 이름을 LCA 프로젝트 관리로 바꾸고 이름·아이콘 영역 전체를 홈 링크로 제공한다. 기존 홈 메뉴와 같은 openHome을 사용하므로 페이지를 다시 불러오지 않는다. 각 화면의 브라우저 제목도 새 이름으로 맞춘다.
- 워크스페이스 메뉴 순서는 홈 → 프로젝트 → 할 일 → 담당 연구원 → 용어사전이다. DOM 순서도 바꿔 키보드 이동 순서와 일치시킨다.
- 홈의 우선 확인할 일 제목을 버튼으로 바꾸고 해당 프로젝트의 자료/고객 의견/검증 지적/개요 탭으로 바로 이동한다. 할 일 탭의 이동 함수를 공통으로 사용한다.
- 클릭 직전에 최신 할 일을 다시 계산한다. 이미 처리됐거나 기록이 달라졌으면 원래 화면으로 이동하지 않고 홈 목록을 갱신해 안내한다.
- 홈에서 연 할 일에는 홈으로 복귀를 제공한다. 원래 홈 스크롤과 해당 할 일 버튼 초점을 복원하며, 항목이 사라지면 홈 제목에 초점을 둔다. 기존 주의 프로젝트 이동·할 일 탭 복귀도 유지한다.
- 갱신으로 홈 버튼을 다시 만들 때 프로젝트뿐 아니라 할 일 버튼의 초점도 유지한다.
- 기존 폼·필터·저장 키·집계·분류·단계 쓰기 조건은 변경하지 않는다. 실제 업무 상태를 클릭만으로 변경하지 않는다.

## 구현과 확인 범위

- `web/index.html`: 이름·홈 링크·메뉴 순서·자산 버전.
- `web/js/app.js`: 공통 할 일 이동과 출발 화면별 복귀·이름 홈 이동·문서 제목.
- `web/js/views/dashboard.js`: 클릭 가능한 할 일 제목·최신 기록 확인 결과 안내·초점.
- `web/css/app.css`: 브랜드 링크와 두 줄 이름·할 일 버튼 스타일.
- JavaScript 구문·Git 공백 검사를 확인했다. 별도 localhost 초기 화면에서 새 브랜드 링크·메뉴 순서·홈 할 일 제목 버튼·새 브라우저 제목 표시를 확인했다. 사용자 탭·저장 기록은 변경하지 않았다.
- 테스트 추가·실행은 하지 않았다. 브랜드 클릭 이동·각 할 일의 상세 이동·처리 후 경고·복귀·입력 유지·키보드·작은 화면의 실제 동작 시험은 하지 않았다. 이전 SPEC의 미확인 범위를 완료로 바꾸지 않는다.
