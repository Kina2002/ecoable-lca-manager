# WEB-041 연구원 한 줄 목록과 접기·펼치기

작성일: 2026-10-18

## 사용자 요청

담당 연구원을 프로젝트 목록처럼 한 명당 한 줄로 배치한다. 연구원 등록과 각자의 담당 프로젝트 목록을 접고 펼치며, 등록 제목을 ‘가상 연구원 등록’에서 ‘연구원 등록’으로 바꾼다. 담당 프로젝트 수는 진행 중과 완료로 나눠 센다.

## 화면

- 연구원 / 회사·부서 / 진행 중 / 완료 / 담당 프로젝트 / 관리의 표를 제공한다. 정보 수정 버튼은 해당 연구원 행에 유지한다.
- 등록 영역은 처음에 접혀 있으며 ‘연구원 등록’을 누르면 기존 이름·회사·부서 입력 폼이 열린다. 접을 때 입력을 지우지 않는다. 저장 결과 안내는 등록 영역 밖에 둬 등록이 접혀 있어도 정보 수정 결과가 보인다.
- 각 행의 ‘펼치기’를 누르면 바로 아래에 해당 연구원의 프로젝트 목록이 나타나며 ‘접기’로 닫는다. 연구원별로 독립적으로 펼친다. 펼친 목록도 진행 중과 완료로 구분하고 0건은 빈 목록 안내를 표시한다.
- 현재 단계가 10(완료·사후관리)이면 완료, 1~9면 진행 중으로 센다. 저장된 연구원 ID로 연결한 프로젝트만 집계하며 동명이인·이름만 있는 기록을 합산하지 않는다.
- 같은 앱 실행 중 연구원 목록 갱신·정보 수정·메뉴 왕복에도 각 연구원 목록의 펼침 상태를 유지한다. 새로고침하면 기본 접힘으로 시작한다. 다른 상세에서 담당 연구원으로 바로 이동하면 해당 연구원 목록을 펼치고 행을 강조한다.
- 연구원 연결 확인과 미정 프로젝트는 별도 접기 영역으로 제공한다. 연구원별 집계와 섞지 않는다.
- 작은 화면에서는 표를 가로로 스크롤하고 펼친 프로젝트의 두 분류는 한 열로 표시한다. 표 스크롤 영역은 키보드로 초점을 받을 수 있다.
- 표 머리글·행 머리글·접기 버튼의 aria-expanded/aria-controls와 목록 제목 연결을 제공한다.

## 저장과 확인 범위

저장 형식·키·연구원 번호·배정·등록/정보 수정 동작은 변경하지 않는다. 기존 가상 사례 안내는 유지하며 등록 제목만 사용자 요청대로 바꾼다. 자료 요청의 두 필터와 다른 화면은 변경하지 않는다.

구문 검사와 `git diff --check`를 확인했다. 사용자 저장 공간과 별도인 127.0.0.1:5189에서 초기 연구원 표·등록 접힘·진행 중/완료 건수와 화면 배치를 확인했다(김하늘 3/0, 박서연 1/1, 이도윤 2/0). 이번 변경에서 자동 테스트를 추가·실행하지 않았으며 실제 등록·수정·메뉴 왕복·접기 클릭·모바일 동작 전체를 실행 검증하지 않았다. WEB-040의 217개 통과는 그 작업 당시 결과이며 이번 재실행 결과가 아니다.
