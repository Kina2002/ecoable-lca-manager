# WEB-043 할 일 한 줄 목록·홈 연구원 필터·용어사전 페이지

구현일: 2026-10-19

## 사용자 합의

- 할 일을 프로젝트 목록처럼 한 항목당 한 행으로 정리하고 남은 날짜를 표시한다.
- 현재 화면에 필요한 새 용어를 용어사전에 추가한다.
- 워크스페이스의 프로젝트 메뉴를 누르면 이전 상세/선택 단계 대신 전체 프로젝트가 보이게 한다.
- 홈에서 담당 연구원별로 정보를 고른다. 사진은 아이디어로 남기고 정보 중심 구성을 우선한다.
- 용어사전은 한 페이지에 6개씩 표시한다.

## 구현

### 할 일

- 데스크톱에서 유형·업무 제목·회사/프로젝트·연구원·기한·내용 펼치기를 한 행으로 배치한다. 좁은 화면에서는 항목 안에서 줄바꿈한다.
- 긴 업무 설명·현재 단계/상태·읽기 전용 안내는 각 행의 ‘내용’에서 펼친다. 같은 실행 중 목록 갱신/필터 전환 시 펼침을 유지한다.
- `D-N`(남음), `D-DAY`(오늘), `D+N`(경과), `기한 미정`을 표시한다. 기존 날짜 계산을 사용하며 새로운 기한을 임의로 저장하지 않는다.
- 이미 제출된 자료의 날짜는 제출 기한이다. ‘제출 완료’를 함께 표시하고 경과 색상을 지연 경고로 쓰지 않는다. 검증 지적은 처리 기한을 사용한다.
- 홈의 먼저 처리할 일에도 같은 D-day 표기를 사용한다.
- 기존 할 일 선정·정렬·검색·연구원 필터·상세 이동 규칙은 유지한다.

### 프로젝트 메뉴

- 어느 화면에서든 프로젝트 메뉴를 누르면 목록을 열고 단계·검색·연구원·목적 조건을 전체로 초기화하며 맨 위로 이동한다.
- 상세의 돌아가기 버튼은 기존 출발 화면/선택 조건으로 돌아가는 용도로 유지한다.
- 자료 요청 상태 필터 두 개는 초기화하지 않는다. 메뉴 이동 시 상세 DOM을 보관하고 같은 프로젝트를 다시 열 때 폼을 다시 만들지 않아 작성 중 입력과 선택 탭을 유지한다. 다른 프로젝트로 이동할 때는 기존처럼 해당 프로젝트 화면을 만든다.

### 홈 연구원 필터

- 등록 연구원(고유 ID/번호로 구분), 담당 미정, 기존 이름 기록, 전체를 선택한다.
- 선택 연구원의 진행 프로젝트에 대해 네 지표·확인 필요 프로젝트·먼저 처리할 일을 함께 집계한다. 자료와 할 일은 선택 프로젝트 ID에 속한 것만 포함한다.
- 담당 프로젝트가 없는 연구원도 명단에서 선택할 수 있다. 0건과 비율 분모 0의 `—`를 표시한다.
- 완료 프로젝트 제외·상위 3건·기존 우선순위는 유지한다. 읽기 실패 경고는 숨기지 않는다.
- 다른 메뉴를 왕복해도 홈 선택을 유지하고 ‘전체 연구원’으로 해제한다. 프로젝트/할 일 탭의 필터와 독립적이다. 홈의 ‘할 일 전체 보기’는 기존 전체 할 일 화면을 연다.
- 사진은 추가하지 않았다. 구체적인 이미지 사용 여부는 후속 사용자 판단 사항이다.

### 용어사전

- 기존 40개에 앱 업무 용어 15개를 추가해 총 55개다. 수집 마감, 목표일, D-day, 자료 승인, 보완, 외부 계산 결과, 결과 해석, 보고서 버전, 변경 이력, 고객 의견, 내부/외부 검토, 검증 차수/지적, 백업·복원이다.
- 추가 원고는 현재 앱의 업무 흐름을 설명한다. 법규·인증의 일반 의무로 표현하지 않는다. 기존 전문 용어/참고 링크와 확인일은 그대로 보관하고 업무 용어 보충일을 구분한다.
- 검색 결과 전체를 먼저 구한 뒤 6개씩 표시한다. 55개는 10페이지이며 마지막에는 1개다.
- 위/아래에 이전·페이지 선택·다음을 제공한다. 처음/끝은 해당 방향을 비활성화한다. 검색/검색 지우기는 1페이지, 검색 결과 0건은 기존 빈 결과 안내로 돌아간다.
- 전체 결과 수와 현재 표시 범위를 구분한다. 페이지를 바꾸면 목록 제목에 초점을 맞추고 해당 위치로 이동한다. 검색 입력은 유지한다.

## 확인 범위와 제한

- 변경 JavaScript 7개 구문 검사, diff 공백 확인.
- 별도 임시 탭에서 실제 현재 기록을 읽어 홈 필터/집계 초기 표시, 할 일 한 행과 기한 미정, 용어사전 총 55개/첫 6개/페이지 이동 컨트롤의 초기 배치를 확인했다. 사용자 원래 탭은 새로고침하지 않았다. 저장/등록/삭제/복원/기록 초기화는 수행하지 않았다.
- 자동 테스트 추가·실행은 하지 않았다. 필터별 수치, 모든 D-day 분기, 페이지 전환/검색 조합, 메뉴 왕복 입력 유지, 모바일의 전체 실행 확인은 남아 있다. 기존 자동검사 217개는 WEB-040 당시 기록이다.
- 저장 키/데이터 형식/단계 조건은 변경하지 않았다. 기존 사용자 자료·보고서 사본·이력은 유지한다.
