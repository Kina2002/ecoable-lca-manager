# WEB-032 자료 등록 두 영역 접기·펼치기

작성일: 2026-10-18

## 사용자 요청과 변경

- 사용자가 여러 자료 한 번에 등록과 자료 하나 등록을 모두 접었다 펼칠 수 있도록 요청했다.
- 두 영역을 각각 독립적인 HTML details/summary로 제공하며 처음에는 둘 다 접는다. 제목을 누르거나 제목에 초점을 두고 Enter/Space로 열고 닫는다. 동시에 열어도 된다.
- 자료 하나 등록도 일괄 등록처럼 전체 너비로 배치하고, 두 등록 영역 아래에 기존 요청 목록을 둔다. 접었을 때 빈 왼쪽 열을 남기지 않는다.
- 요청이 없는 프로젝트에서 일괄 등록을 자동으로 펼치던 WEB-031 초기 정책을 이 요청으로 대체한다.
- 접을 때 폼을 초기화하거나 다시 만들지 않으므로 미저장 선택·문장·날짜를 유지한다. 필터와 일반 목록 갱신도 두 영역의 열림 상태를 바꾸지 않는다.
- 상세를 나갔다 다시 열거나 페이지를 새로고침하면 두 영역은 다시 접힌다. 초안을 영구 저장하는 기능은 아니다.
- 개별·일괄 저장 규칙, 기존 저장 기록·키, 두 자료 상태 필터, 완료 확인과 단계 이동은 변경하지 않는다.

## 구현과 확인 범위

- `web/index.html`: 개별 폼을 details로 감싸고 summary 제공, 자산 버전 갱신.
- `web/js/views/request-batch.js`: 초기 자동 펼침 제거, 사용자 열림 상태 유지.
- `web/css/app.css`: 개별 summary 스타일과 한 열 배치.
- JavaScript 구문·Git 공백 확인과 별도 localhost 초기 접힘 배치만 확인했다. 테스트 추가·실행과 입력 유지·저장 흐름의 실행 시험은 하지 않았다. 사용자 탭·저장 기록은 수정하지 않았다.
