# WEB-018 자료 수집 완료와 데이터 검토 시작

## 1. 합의한 범위

2026-10-17 사용자는 제안한 **자료 수집 완료 → 데이터 검토 단계 이동** 기능을 승인했다. 자료 요청이 최소 한 건 있고 모두 제출된 경우, 담당자가 별도 버튼을 눌러 프로젝트를 3단계에서 4단계로 옮긴다. 수집과 승인, 프로젝트 전체 완료는 구분한다.

## 2. 화면과 조건

- 수집 단계 상세의 현재 단계 아래에 ‘자료 수집 완료 확인’을 표시한다. 개요·범위와 자료 요청 탭에서 모두 볼 수 있다.
- ‘자료 수집 완료 · 검토 시작’ 버튼은 조건이 충족되면 활성화한다.
- 삭제하지 않은 현재 프로젝트의 요청만 센다. 최소 한 건이 있어야 한다.
- ‘제출됨·검토 중·승인’이며 받은 자료 기록이 있는 항목은 제출 확인에 포함한다. ‘요청·보완 요청’은 이동을 막는다.
- 0건이면 요청 등록·받은 자료 기록을 안내한다. 미완료가 있으면 제출 확인 건수와 요청 번호·자료 구분·상태를 안내한다.
- ‘자료 요청에서 확인’을 누르면 해당 상세의 자료 요청 탭을 연다. 자료 등록·받은 자료 저장·검토·보완·삭제·복원 후 조건을 다시 계산한다. 상태 필터로 가려진 요청도 검사한다.
- 수집 마감일을 입력 중이면 먼저 저장하거나 원래 값으로 되돌리도록 안내한다. 날짜 미정 자체는 이동을 막지 않는다.
- 클릭할 때도 최신 요청과 저장된 단계를 다시 읽는다. 조건에 맞으면 단계 3→4만 저장한다. 조건 충족만으로 자동 이동하지 않는다.

## 3. 이동 결과

- 상세 단계는 ‘데이터 검토’, 목록의 자료 현황과 수집 일정 배지는 ‘자료 수집 완료’가 된다. 프로젝트 목표 D-day와 개별 자료의 D-day는 각 규칙을 따른다.
- 단계별 건수와 수집 단계 자료 목록을 갱신한다. 기존 목록 필터 선택은 유지한다.
- 요청의 상태·기한·받은 자료·검토 결과를 바꾸지 않는다. 제출 자료를 자동 승인하거나 자동 검토하지 않는다.
- 상세 전체를 다시 만들지 않아 자료 요청 탭·상태 필터·등록 폼의 작성 중 값이 유지된다.
- 검토 단계에 들어간 수집 일정은 읽기 전용이다. 이전 탭에 남은 일정 입력도 최신 단계를 확인해 저장을 거절한다.
- 검토 중 보완 요청·새 자료 기록으로 개별 요청 상태가 바뀌어도 프로젝트를 자동으로 수집 단계로 되돌리지 않는다. 이번 범위는 3→4 연결이다. 4→5, 단계 되돌리기·사유를 남기는 강제 이동은 후속 합의 대상이다.

## 4. 저장과 기존 기록

기존 `ecoable-lca-manager.scope.v1`의 stage에 4를 허용한다. 원래 계약·범위·수집 단계인 프로젝트만 이 기록을 가질 수 있고, 기본 단계보다 이전으로 저장된 기록이나 미확정 범위의 3·4단계 기록은 거절한다. 샘플의 숫자 기준량은 값이 같은 문자열로 보관해 기존 검증 형식과 맞춘다.

별도 저장 키는 추가하지 않는다. 기존 1→2→3 기록과 범위·담당자·메모를 복원하며, 프로젝트·연구원·요청 저장소는 단계 이동으로 수정하지 않는다. 쓰기 실패, 손상된 요청/범위 저장본, 다른 화면의 단계 변경은 성공으로 처리하거나 덮어쓰지 않는다.

## 5. 확인 결과

- 자동 검사 **148개 통과**: 기존 138개 + 전환 관련 10개.
- 신규 프로젝트 등록→담당자→범위 확정→수집→검토→재로딩, 기본 수집 샘플의 3→4 복원, 완료 D-day·단계 건수, 요청/보완/0건 차단, 삭제·다른 프로젝트 제외, 클릭 시 최신 요청 재검사, 기존 자료·검토 기록 보존, 쓰기 실패·손상·다른 탭의 변경 거절을 확인했다.
- JavaScript 구문과 Git 공백 오류를 확인했다.
- 실제 미리보기 `127.0.0.1:5180`에서 요청 0건과 비활성 버튼을 확인했다.
- 별도 브라우저 저장 공간인 `localhost:5180`에서 가상 요청 등록→부족 항목 안내→받은 자료 저장→버튼 활성화→검토 시작→새로고침 복원까지 확인했다. 전환 후 승인 0/1건이며 개별 자료는 제출됨으로 유지됐다. 자료 상태 필터와 입력 초안도 전환 후 유지됐다.
- 사용 중인 `127.0.0.1`의 샘플과 입력 기록은 이 전환 시연에서 변경하지 않았다. 직접 시간 경과를 기다리거나 실제 고객 자료로 확인하지 않았다.
