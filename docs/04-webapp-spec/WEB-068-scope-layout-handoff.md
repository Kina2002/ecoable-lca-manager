# WEB-068 범위 입력 배치·협의 메모 양식·노트북 인수인계

기준량/단위/경계/기간 입력칸이 필요보다 넓다는 사용자 피드백과, 협의 메모 양식·다른 노트북에서 이어가기 요청을 반영했다. 작업 완료일은 2026-10-20(한국 시간)이다.

## 화면 변경

- 범위 편집 폼만 최대 880px로 제한한다. 범위 상태는 220px, 기준량/단위는 140px, 경계는 260px 이내로 모아 배치한다.
- 날짜는 각각 220px 이내에서 텍스트 입력+짧은 달력 버튼을 나란히 둔다. 시작/종료의 접근성 이름은 구분하고 기존 날짜 포맷/달력 연결을 유지한다.
- 날짜의 숫자 8자리 안내는 공통 한 줄로 제공한다. 기간 사유는 두 줄 입력과 접힌 예시로 줄인다. 12개월이면 빈칸으로 둘 수 있음을 안내하며 저장 조건은 바꾸지 않는다.
- 1,200px 이하 화면에서는 기간 사유를 다음 줄로, 680px 이하에서는 경계를 전체 폭과 날짜 한 열로 배치한다. 다른 scope-form/착수/일정 폼은 바꾸지 않는다.
- 협의 메모에 대상 제품·평가 기준량·포함/제외 범위·자료 기준기간·적용 기준·미정 사항의 여러 줄 안내를 넣는다. 기존 메모가 있어도 접힌 **협의 메모 예시 양식**을 펼쳐 가상 예시를 볼 수 있다.
- **빈 메모에 항목 넣기**는 내용이 없는 메모에 빈 항목만 넣고 입력 변경 이벤트를 전달한다. 기존 메모가 있으면 비활성화하며 덮어쓰지 않는다. 저장이나 다른 범위 칸 자동 채우기/기준 자동 선택은 하지 않는다.
- 저장 키/도메인/업무 단계/필터/과거 사본을 변경하지 않는다. AI 메모 분석은 추후 계획이다.
