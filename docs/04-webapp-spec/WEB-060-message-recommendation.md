# WEB-060 기한별 안내문 추천과 종합 안내

## 목적과 규칙

고객에게 연락할 때 기한 지난 미제출 자료, 보완 자료, 아직 기한 전인 자료를 섞어 잘못 설명하지 않도록 돕는다. 설계서의 기한 초과 우선→보완과 임박 동시→보완→임박→정보 확인→없음 순서를 적용한다. 임박은 오늘부터 3일 뒤까지다. 기한 초과 또는 보완과 임박이 함께 있으면 ‘종합 제출·보완 안내’를 추천한다. 그렇지 않으면 기존 전용 종류를 추천한다. 멀리 남은 요청만 있으면 처음 요청을 자동 추천하지 않고 직접 선택하도록 한다.

## 화면과 내용

요청문 편집기에 추천 종류·판단 사유·집단별 건수를 표시한다. ‘추천 대상 선택’은 종류와 자료를 고르기만 하며, 사용자가 만들기를 눌러 초안을 만든다. 직접 수정 중인 글은 기존 교체 확인을 유지한다. 추천 종류에 표시를 붙이되 다른 종류도 선택할 수 있다.

종합 안내는 세 집단을 제목으로 나누며 선택한 자료마다 기존 기한을 넣는다. 보완 자료는 기존 요청 기한과 새 보완 기한을 구분하고 새 일정은 별도 협의로 적는다. 제출됨/검토 중/승인/해당 없음/삭제 자료는 독촉에서 뺀다. 변경된 보완 사유와 날짜 경계는 복사 전 최신 기준 검사에 반영한다. 새 종류의 실제 발송 사본도 기존 로그·백업으로 보관한다.

## 검증과 설명

전체 자동검사 265개 통과. 추천 우선순위, 집단 분리, 받은 자료 제외, 무변경 생성, 보완 사유 변경 시 복사 차단을 확인했다. 구문·공백 검사 통과. 실제 클릭·외부 복사/발송은 미확인이다. AI나 메일 자동 발송은 포함하지 않는다.

“컴퓨터는 누가 늦었는지 추측하지 않습니다. 저장된 제출 여부와 날짜를 비교해 연락 대상을 제안하고, 사람이 내용을 확인한 뒤 외부에서 보냅니다.”
