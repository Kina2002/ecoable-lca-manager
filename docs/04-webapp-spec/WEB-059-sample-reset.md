# WEB-059 기본 샘플 초기화

## 목적

한 번의 연습을 마친 뒤 새 공책으로 바꾸듯, 기본 가상 프로젝트 7개와 기본 연구원으로 다시 시작한다. 실행일 기준의 샘플 일정을 만든다. 사용자가 직접 만든 프로젝트와 업무 기록, 저장한 요청 기본 문장을 포함한 현재 데이터 전체를 교체한다.

## 화면과 보호

설정의 접힌 ‘새 연습 시작’에서 교체 대상을 읽는다. 기존 백업 내려받기를 완료/요청한 뒤 실제 파일 보관과 저장 전 입력 보관·다른 창 닫기를 사용자가 확인해야 버튼을 사용할 수 있다. 기본 다운로드 방식은 파일 저장 완료를 앱이 확인할 수 없음을 안내한다. 백업 뒤 기록이 바뀌면 교체를 거절하고 다시 백업하도록 한다.

복원과 같은 저장 저널·공통 잠금·이전 값 되돌리기를 사용한다. 성공하면 새로고침이 필요하고 이전 창의 저장을 막는다. 이전 백업은 그대로 복원할 수 있다. 초기화 기능을 만들었다는 이유로 사용자의 실제 기록을 초기화하지 않는다.

## 검증

전체 자동검사 263개 통과. 메모리 저장소에서 계획 조회 무변경, 8개→기본 7개→백업 8개 복원, 오래된 백업 기준 거절, 저장 실패 시 기존 데이터 복구를 확인했다. 구문·공백 검사 통과. 실제 브라우저 파일 저장/확인/초기화 클릭은 미확인이다.

## 면접 설명

“초기화는 여러 종류의 기록을 동시에 바꿉니다. 중간에 실패해 일부만 지워지는 일을 막으려고 원래 기록을 먼저 보관하고, 실패하면 원래대로 되돌리도록 구현했습니다.”
