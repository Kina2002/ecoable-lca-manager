# WEB-057 홈 전체 조회와 프로젝트 정렬

## 목적과 사용법

홈은 책상 위 오늘 볼 서류, 프로젝트 목록은 모든 서류가 들어 있는 서랍이다. 홈의 우선 3개 아래 ‘더 보기’를 누르면 같은 연구원 조건의 전체 주의 프로젝트·할 일을 펼친다. 다시 3개만 볼 수 있다. 별도의 ‘할 일 전체 보기’도 유지한다. 완료 프로젝트 수는 선택 연구원의 전체 프로젝트 중 10단계 건수이며, 업무 진행률로 해석하지 않는다.

프로젝트 목록은 등록 순서/최근 등록 먼저/목표일 빠른 순/회사 이름순/업무 단계순으로 정렬한다. 목표일 정렬에서 완료·날짜 미정은 뒤로 보낸다. ‘확인 필요한 프로젝트만’은 홈과 같은 목표일·수집 마감·현재 할 일 기준으로 고르며 단계·검색·연구원·목적 조건과 함께 적용한다. 자료 상태 필터 두 개는 유지한다. 조건 초기화는 추가 정렬·주의 조건도 해제하고 단계 선택은 유지한다.

## 데이터와 오류

조회만 바꾸고 저장 키·입력·업무 단계·원본 명단 순서를 바꾸지 않는다. 완료 프로젝트도 갱신/점검 할 일이 있으면 주의 대상이다. 기록을 읽지 못하면 확인 가능한 부분만 계산했다는 경고를 표시한다. 단계별 전체 건수는 조건과 별개다.

## 확인

전체 자동검사 259개 통과. 추가 검사는 전체/요약의 순서, 연구원별 완료 건수, 복합 필터, 원본 보존, 완료/미정 목표일 정렬을 확인한다. JavaScript 구문·공백 검사 통과. 실제 브라우저 클릭·배치·복귀 초점의 사용 시험은 미확인이다.

## 면접에서 설명하기

“목록을 필터링하는 것은 서랍에서 조건에 맞는 서류만 꺼내는 일이고, 정렬은 꺼낸 서류의 순서를 바꾸는 일입니다. 홈과 목록에서 같은 주의 기준을 사용해 서로 다른 결과로 혼동하지 않게 했습니다.”
