# WEB-034 할 일 분류 한 줄 설명

작성일: 2026-10-18

- 사용자 요청: 할 일 분류 버튼 아래, 할 일 검색 위에 간단한 한 줄 설명을 표시한다.
- 전체와 일곱 분류마다 쉬운 설명을 준비하고 선택한 분류에 맞춰 바꾼다. 조건 초기화 시 전체 설명으로 돌아간다. 좁은 화면에서는 자연스럽게 줄바꿈한다.
- 기존 분류 위의 긴 안내를 이 위치의 선택별 설명으로 대체한다. 설명은 상태 영역이며 같은 내용으로 반복 갱신하지 않는다.
- 최신 기록 확인은 저장된 원래 기록을 다시 읽어 할 일을 계산하는 기존 동작이다. 저장·사이트 새로고침·외부 자료 수신 기능이 아니다. 이번에 버튼 동작이나 분류·검색·저장 규칙은 바꾸지 않는다.
- 변경 파일: `web/js/views/tasks.js`, `web/index.html`.
- JavaScript 구문·Git 공백·별도 localhost의 초기 전체 설명 표시만 확인했다. 테스트 추가·실행과 각 분류 전환·검색·실제 기록 갱신 시험은 하지 않았다. 사용자 탭과 저장 기록은 변경하지 않았다.
