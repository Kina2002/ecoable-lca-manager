# WEB-058 기본 요청 문장 설정

## 왜 필요한가

자료마다 매번 같은 요청을 다시 쓰지 않도록, 자주 쓰는 문장을 저장하는 메모장이다. 설정에서 11개 자료 구분을 고르고 1~1,000자의 문장을 저장한다. 이 구분만 앱 기본값으로 되돌릴 수도 있다. 수정 중인 구분별 입력은 화면에서 유지하고 ‘수정 버리고 최신 문장 불러오기’로 새 저장본을 읽는다.

## 적용 범위

한 자료 등록에서 구분을 고를 때와 여러 자료 등록의 초기 문장에 적용한다. 일괄 등록을 다시 펼칠 때 사용자가 아직 바꾸지 않은 문장은 최신 기본값을 읽고, 작성 중인 문장은 유지한다. 기존에 등록한 자료 요청·발송 사본은 수정하지 않는다. 초기화와 함께 지워지고 JSON 백업에는 포함된다.

## 저장·오류

새 키 대신 requests.v1의 선택 templates(revision, values)를 사용한다. 기존 파일은 수정 없이 기본 문장을 읽는다. 잘못된 구분·빈 내용·초과 길이·손상 형식을 거절한다. 공통 저장 잠금과 설정 차수 비교로 다른 창의 수정을 보호한다. 프로젝트 삭제는 공유 설정을 유지한다.

## 확인

전체 자동검사 261개 통과. 기본값 무쓰기 읽기, 재읽기/기본값 복귀, 기존 자료 보존, 충돌/실패, 백업과 프로젝트 삭제 시 공유 설정 보존을 확인했다. 구문·공백 검사 통과. 실제 브라우저 입력·저장·작은 화면 사용은 미확인이다.

## 쉬운 설명

“요청 문장은 도장 원본입니다. 도장 원본을 바꿔도 이미 찍어 둔 종이가 바뀌지는 않습니다. 이후 새 요청을 만들 때 새 문장을 사용할 뿐입니다.”
