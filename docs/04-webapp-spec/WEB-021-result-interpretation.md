# WEB-021 결과 해석 시작과 담당자 해석 기록

후속 WEB-022에서 보고서 단계(7)에서도 해석을 수정하도록 확장했다. 보고서 작성 중 계산 결과가 바뀌면 해석과 초안을 순서대로 갱신할 수 있다. 아래의 6단계 전용·6→7 미구현 설명은 WEB-021 당시 범위이며 최신 조건은 [WEB-022](WEB-022-report-draft.md)를 우선한다.

## 합의한 범위

2026-10-17 사용자는 직전 제안한 결과 해석 기능을 하위 에이전트에게 맡기도록 명시했다. 승인 자료·외부 계산 결과 흐름 뒤에 결과 해석 단계와 사람이 쓰는 해석 기록을 연결한다. 내부 LCA 계산과 AI는 기본 기능 완성 후 검토한다.

## 화면과 단계

- 프로젝트 상세에 네 번째 `결과 해석` 탭을 추가한다. 기존 회사별 자료 필터와 전체 수집 상태 필터를 유지한다.
- 단계 5에서 현재 미삭제 요청이 최소 한 건이고 모두 승인돼 있으며, 저장된 외부 계산 결과가 존재하고 그 당시 승인 자료·평가 범위가 현재와 일치할 때만 `결과 해석 시작`을 활성화한다.
- 클릭 시 최신 scope와 외부 계산 결과·자료를 다시 읽어 5→6만 저장한다. 계산 결과 저장이나 탭 선택으로 단계를 자동 변경하지 않는다.
- 범위 저장소는 6단계를 읽고 복원한다. 원래 샘플 6·8·10단계는 그대로 표시한다. 저장 실패 시 단계와 기존 기록을 보존한다.
- 현재 계산 결과 버전·계산일·제품 기준량·범위·기간·도구·평가 방법·파일 이름과 지표를 보여준다.

## 해석 기록

단계 6에서 다음 네 항목을 각각 필수 1~3,000자로 기록한다. 확인하지 못한 것은 미확인과 이유를 적을 수 있다.

1. 주요 결과
2. 영향이 큰 원인
3. 개선 검토안
4. 가정·한계

담당자가 외부 분석을 읽고 확인 체크 후 저장한다. 앱은 기여도·원인·개선 효과를 추정하거나 계산하지 않는다. 결과가 없거나 최신 원자료와 일치하지 않으면 해석 저장을 막는다. 단계 5 이하와 7 이상은 기록할 수 없다. 해석 저장으로 6→7 보고서 단계로 이동하지 않는다.

## 계산 근거와 변경 보호

- 해석마다 당시 외부 계산 결과 전체 사본(계산 결과 버전·당시 범위·승인 자료 포함)을 보관한다. `해석 당시 계산 결과 보기`에서 당시 요약·지표를 확인한다.
- 계산 결과 재저장(같은 값이어도 버전 변경), 자료 재기록·승인 변경, 요청 추가·삭제, 평가 범위 변경은 해석 재확인 대상으로 표시한다. 프로젝트 단계·일정 변경 자체는 계산의 근거 변경에 포함하지 않는다.
- 기존 해석과 작성 중인 문장은 유지한다. 오래된 계산 기준으로 저장하면 거부한다.
- 최신 자료에 맞는 외부 결과를 준비한 뒤 `해석 기준 다시 확인`으로 입력 기준을 갱신한다. 문장은 유지하고 확인 체크를 해제한다. 내용을 다시 읽고 수정·확인한 뒤 저장한다.
- 해석 버전의 낙관적 충돌 검사로 다른 화면에서 저장한 기록의 무심한 덮어쓰기를 막는다. 프로젝트별 최신 해석 한 건이며 과거 해석 버전 목록은 없다.
- 손상된 해석·계산·자료·범위 기록과 저장 실패는 기존 기록을 보존하고 작업을 막는다. 자동 복구·삭제를 하지 않는다.

## 저장과 호환

새 키 `ecoable-lca-manager.interpretation.v1`에 `{version:1, records:{프로젝트ID:해석}}` 형식으로 저장한다. 해석에는 네 문장, confirmed, projectId, revision, calculation 사본, createdAt, updatedAt을 저장한다. 기존 다섯 저장 키를 그대로 사용하며 읽기·이동·해석 저장으로 요청이나 계산 결과를 다시 쓰지 않는다. GitHub에는 코드·명세만 올라가고 브라우저 입력은 이동하지 않는다.

## 확인한 내용과 한계

이번 요청에서 자동 테스트 추가·실행은 하지 않았다. WEB-020의 166개 통과 기록은 이전 작업의 결과이며 이번 변경의 통과 수로 주장하지 않는다. JavaScript 구문 검사와 변경 코드 검토를 수행했다.

별도 localhost 저장 공간의 가상 자료로 실제 UI를 확인했다. 사용자 127.0.0.1 저장 자료는 변경하지 않았다.

- 이전 WEB-020의 외부 결과 버전 2·승인 1/1과 저장 기록을 그대로 읽음
- 결과 해석 탭에서 준비 완료 확인, 명시적 버튼으로 5→6 이동
- 네 항목·확인 체크 저장, 새로고침 후 6단계와 해석 복원
- 외부 결과 1.3300→1.4300 수정 저장 시 기존 해석 유지·오래됨 안내
- 오래된 기준의 해석 저장 차단, 기준 재확인·내용 수정 후 해석 버전 2 저장
- 브라우저 오류 로그 없음, 실제 화면 배치 확인

현재 구현에서 자동 회귀 검사·모든 실패 분기의 실제 UI 재현·다른 탭 동시 저장·모바일 전용 크기는 확인하지 않았다. 내부 계산·AI·보고서 작성·6→7·단계 되돌리기·파일 업로드·이력 조회는 후속 별도 합의 범위다.
