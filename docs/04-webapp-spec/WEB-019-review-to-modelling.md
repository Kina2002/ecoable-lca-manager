# WEB-019 자료 검토 완료와 계산 단계 이동

## 1. 사용자 합의

2026-10-17 사용자는 자료 검토 화면에 승인 건수와 미승인 자료를 표시하고, 모두 승인됐을 때 별도 버튼으로 계산(모델링) 단계에 들어가는 기능을 승인했다. 범위는 프로젝트 단계 4→5 연결이며 실제 LCA 계산은 포함하지 않는다.

## 2. 조건과 화면

- 검토 단계 상세 상단에 ‘자료 검토 완료 확인’과 **승인 건수 / 전체 자료 수**를 표시한다.
- 현재 프로젝트의 삭제하지 않은 요청이 최소 한 건이어야 한다. 0건은 승인 0/0건과 안내를 표시하며 완료 처리하지 않는다.
- 모든 요청이 ‘승인’이고 받은 자료·검토 기록이 있어야 ‘자료 검토 완료 · 계산 단계로’ 버튼을 활성화한다. 요청 저장소의 기존 검증은 승인 체크와 기록의 일치 여부도 검사한다.
- 요청·제출됨·검토 중·보완 요청은 미승인이다. 요청 번호·자료 구분·현재 상태로 안내한다. 다른 프로젝트와 삭제된 요청은 조건에서 제외한다.
- 자료 등록·삭제·복원·받은 자료 재기록·검토 결과 저장 후 건수와 버튼을 갱신한다. 자료 상태 필터가 일부 요청을 숨겨도 전체 요청을 검사한다.
- 조건 충족만으로 단계를 자동 변경하지 않는다. 클릭할 때 최신 요청·단계·범위를 다시 확인하고 4→5만 저장한다.
- 계산 단계에서는 ‘자료 검토 완료’와 다음 작업 안내를 표시한다. 실제 환경영향 계산은 아직 시연 앱에서 실행하지 않는다는 안내를 함께 표시한다.

## 3. 결과와 보존

- 상세 단계와 목록은 ‘계산(모델링)’이 되고, 단계별 건수도 갱신한다.
- 목표일·수집 마감일과 개별 자료·증빙 이름·승인 체크·검토 메모·기한은 변경하지 않는다.
- 상세 전체를 다시 만들지 않아 자료 요청 탭·상태 필터·폼의 입력 초안을 유지한다.
- 기존 수집 3→검토 4 연결을 유지하며, 수집에서 검토로 이동한 직후에도 승인 건수를 안내한다.
- 계산 단계 이후 받은 자료를 다시 기록하면 기존 규칙에 따라 그 요청의 승인이 초기화된다. 프로젝트 단계를 자동으로 되돌리지는 않는다. 단계 되돌리기, 5→6, 실제 배경 DB 연결과 LCA 계산은 후속 합의 대상이다.

## 4. 저장과 호환

`ecoable-lca-manager.scope.v1`의 단계에 5를 추가한다. 기본 단계가 계약·범위·수집·검토인 프로젝트의 저장 기록을 읽을 수 있다. 기본 단계보다 이전이거나 미확정 범위의 단계 3 이상인 기록은 거절한다. 원래 검토 단계인 다온케미칼 샘플과 직접 등록해 순서대로 이동한 프로젝트를 지원한다.

새 저장 키는 만들지 않는다. 기존 단계 1~4 기록을 쓰기 없이 읽으며, 받은 자료·검토가 들어 있는 requests.v1을 단계 이동으로 덮어쓰지 않는다. 손상된 기록, 쓰기 실패, 다른 화면의 단계 변경은 이동 성공으로 처리하지 않는다.

## 5. 확인 결과

- 자동 검사 **156개 통과**(기존 148개 + 검토 전환 8개).
- 미승인 전 상태와 0건 차단, 승인 기록 필수, 원래 검토 샘플 4→5 복원, 수집→검토→승인→계산 복원, 다른 프로젝트·삭제 제외, 재기록·신규 요청의 클릭 시 재검사, 쓰기 실패·손상·다른 탭 변경·중복 이동·건너뛰기 거절, 기존 기록 보존을 확인했다.
- JavaScript 구문·Git 공백 오류를 확인했다.
- 실제 `127.0.0.1:5180`의 다온케미칼 상세에서 승인 0/0건과 비활성 버튼을 확인했다.
- 별도 저장 공간인 `localhost:5180`의 가상 자료로 승인 0/1건과 미승인 안내→검토 체크·승인→승인 1/1건과 버튼 활성화→계산 단계 이동→새로고침 복원을 확인했다. 승인 상태 필터와 작성 중 초안이 이동 후 유지됐으며 브라우저 오류는 없었다.
- 사용자 미리보기의 입력 기록은 변경하지 않았다. 실제 고객 자료나 외부 LCA 도구를 사용하지 않았다.

## 6. 설명 예시

“자료를 모두 받으면 검토 단계로, 검토해서 모두 승인하면 계산 단계로 넘어가게 했습니다. 두 시점의 조건을 나누고, 미승인 자료가 있으면 어떤 자료를 확인해야 하는지 보여줍니다. 단계 이동은 담당자가 버튼으로 결정하며 승인한 원본 기록은 그대로 보관합니다.”
