# WEB-048 자료 출처 안내

기준: 설계서 v02 F-10의 ‘자료 출처(공개 데이터 출처·기준일·이용 조건)’와 9-1의 출처·확인 상태 표시. 사용자가 WEB-047 확인 후 “우선 만들어봐. 보면 더 이해될 것 같아”라고 요청했다.

## 왜 만드는가

받은 자료 한 건의 출처는 프로젝트 기록에서 관리한다. 반면 공개 자료는 프로그램이 규칙·화면·예시를 만들 때 참고한 출처다. 두 종류를 혼동하면 공개 자료의 수치가 고객사 프로젝트에 이미 적용된 것처럼 보일 수 있다. 설정에서 공개 자료의 제공처·기준일·이용 조건과 실제 활용 범위를 함께 보여 준다.

## 화면

설정 첫 부분에 세 자료의 카드를 배치한다. 카드에는 활용 범위, 제공처, 자료 기준일, 이용 조건, 확인 상태와 원문 링크가 있다. 확인일은 2026-10-19로 고정해 자료 기준일과 구분한다. 좁은 화면에서는 카드를 한 줄씩 표시한다.

1. **환경성적표지 유효 인증현황**: 한국환경산업기술원·공공데이터포털. 파일명 기준 2026-06-30. 포털에 무료·이용허락범위 제한 없음으로 표시. 인증번호·제품군·시작/종료일 형식 참고. 실제 기업 기록은 샘플 프로젝트에 복사하지 않음. [원문](https://www.data.go.kr/data/15089157/fileData.do).
2. **환경성적표지 평가계수**: 한국환경산업기술원·공공데이터포털. 원문 설명의 2021년도 기준. 포털에는 무료·제한 없음으로 표시되나, 다른 제공처의 상업적 이용 안내와 적용 관계는 **확인 필요**. 데이터셋 출처 관리 설계의 참고이며 계수 수치는 앱에 적용하지 않음. [원문](https://www.data.go.kr/data/15120968/fileData.do).
3. **환경성적표지 작성지침**: 국가법령정보센터 원문 링크. 업무 설계의 참고이나 이번 확인에서 최신 원문을 직접 열지 못했다. 기준일·최신 조문·이용 안내는 **확인 필요**로 표시. [원문 링크](https://www.law.go.kr/행정규칙/환경성적표지작성지침).

## 범위와 보존

이 화면은 코드에 포함한 읽기 전용 안내다. 공개 데이터 파일을 자동 다운로드하거나 프로젝트·계수값에 입력하지 않는다. 별도의 저장 키나 개인정보가 없으며 백업·복원·받은 자료의 출처 기록은 변경하지 않는다. 원문 링크는 새 탭으로 열고 이용 조건은 최종 사용 전에 원문에서 다시 확인한다.

## 확인

- 원문 두 곳의 기준·이용허락 표기를 2026-10-19 공식 공공데이터포털에서 대조했다. 법령 링크의 최신 내용은 미확인으로 남겼다.
- 전체 자동검사 **229개 통과**. 로컬 서버 HTTP 200과 안내 문구·공공데이터포털 원문 링크 2개·CSS 자산 제공, Git 공백을 확인했다. 이번 변경에는 JavaScript가 없다. 브라우저 클릭·모바일 배치의 직접 조작은 아직 확인하지 못했다.

면접 설명: “프로젝트가 받은 개별 자료의 출처와, 프로그램 설계에 참고한 공개 자료는 목적이 다릅니다. 설정에는 공개 자료의 제공처·기준일·이용 조건·확인 상태를 모아 두었습니다. 실제 공개 자료의 숫자나 회사 기록을 시연 프로젝트에 자동으로 넣지 않았고, 불명확한 조건은 ‘확인 필요’로 표시했습니다.”
