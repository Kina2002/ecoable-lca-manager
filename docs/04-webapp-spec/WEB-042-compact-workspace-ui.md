# WEB-042 화면 밀도와 주요 정보 배치 개선

작성일: 2026-10-19

## 사용자 합의

큰 버튼·블록, 과도한 스크롤, 주요 정보가 잘 보이지 않는 문제를 개선한다. UI 인수인계 지침을 사용자가 ‘개선해봐’라고 승인해 구현했다.

## 공통 규격

- `web/css/compact.css`를 기존 CSS 뒤에 로드한다. 상단 바 77→48px, 본문 상단 여백 43→20px, 기본 카드 여백 27/28→16px로 줄인다. 반복되는 영문 장식 제목을 화면에서 숨긴다.
- 일반 버튼 34px, 주요 버튼 36px 기준으로 정리하고 grid/flex에서 불필요하게 늘어나지 않게 정렬한다. 760px 이하에서는 주요 버튼 높이를 44px로 유지한다.
- 작은 도움말 일부는 12px로 키우고 대비·줄 간격을 정리한다. 빈 오류/상태 영역의 공간만 없애며 내용이 있는 안내는 유지한다.
- 홈 수치/우선 목록, 할 일·연구원·설정 등에도 공통 여백과 버튼 규격을 적용한다. 수치·기한은 굵은 글씨와 기존 상태 라벨로 구분한다.

## 목록·상세

- 단계 버튼 최소 높이 88→56px, 회사명과 번호는 같은 줄로 정리한다. 상세 일정은 펼쳐 보고 목표일·수집 상태·승인 건수는 기본 목록에 남긴다.
- 상세의 돌아가기·회사/제품·관리 버튼을 한 행으로 모은다. 같은 돌아가기 버튼 노드를 옮겨 원래 이벤트를 유지한다. 상단 요약은 현재 단계·목표일을 먼저 보인다. 큰 화면에서는 탭을 스크롤 상단에 유지하며 줄바꿈을 허용한다.
- 수집 일정은 날짜와 D-day를 짧은 행으로 보여주고 수정 폼은 접는다. 입력/이벤트를 재생성하지 않으므로 접어도 입력은 남는다.
- 목적/범위는 짧은 항목을 여러 열로 배치한다. 1101px 이상에서는 범위 정보 세 열을 사용한다. 설명은 카드별 ‘항목 설명’으로 모으고 긴 메모를 자르지 않는다.
- 수집 이후 읽기 전용 범위 기록은 접되 ‘기록 보기’가 펼쳐 이동한다. 기본정보/범위 갱신 시 카드 설명의 열림 상태를 유지한다.

## 자료 요청

- 수집/검토 상태와 다음 단계 버튼을 짧게 정리한다. 단계 안내와 미충족 자료 목록은 펼쳐 보고 현재 조건과 안내는 기본 화면에 남긴다.
- 접힌 요청문/일괄 등록/개별 등록을 세 칸으로 나란히 배치한다. 열면 전체 너비를 사용하고 작은 화면은 한 열이다.
- 구분·번호·상태·기한·처리 버튼을 한 행에 모은다. 받은 값/단위·증빙 이름·보완 사유는 기본 화면에 남기고 요청 전문·자료/검토 기록·지침은 펼쳐 본다. 번호별 펼침 상태를 목록 갱신 시 유지한다.
- 두 자료 필터·독립 선택·등록 중 입력·요청문 편집은 유지한다. 원래 자료/검토 dialog와 이벤트 연결을 사용한다.

## 후속 탭

계산 결과·해석·보고서 변경·고객 의견·검토 방식/내부 확인·외부 차수/지적/답변·인증 완료 근거/제출/최종 완료의 긴 입력 폼을 접고 펼친다. `views/compact.js`는 form 노드를 그대로 감싸며 저장/검증 로직은 변경하지 않는다. 현재 근거·상태·보관 정보와 오류는 원래 조건을 따른다. 원래 form이 숨겨지면 접기 영역도 CSS `:has()`로 숨긴다. 구형 브라우저 확인은 남아 있다.

## 확인 범위

- 변경 JavaScript 15개 파일 구문, HTML의 로컬 자산 연결, 공백을 확인했다. 자동 테스트 추가·실행은 없다. 217개 통과는 WEB-040 당시 결과다.
- 사용자와 분리한 `127.0.0.1:5190`에서 홈·프로젝트 목록·상세 개요·자료 요청·계산·검토/검증·인증/등록의 초기 배치를 확인했다. 가상 자료 두 건을 등록해 짧은 자료 행도 확인했다. 사용자 5180 탭·기록은 변경하지 않았다.
- 캡처 크기는 1265×712 및 이후 1280×720이다. 홈 요약/우선 목록과 상세 주요 정보를 첫 화면에서 읽는 배치를 확인했다. 모든 상세 내용·전체 프로젝트가 한 화면에 들어간다고 보장하지 않는다.
- 전체 저장/수정/복원·보고서/검증/인증 회귀 시험과 모바일·모든 브라우저·1366×768 확인은 하지 않았다. 사용자 화면 피드백과 좁은 화면의 미세 조정은 후속 확인이다.
- 저장 키/형식·도메인 규칙·단계 조건은 유지한다. 내부 계산·AI·메일 발송은 추가하지 않는다.
